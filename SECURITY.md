# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a potential security vulnerability within **DocuReason**, please report it responsibly:

1. **Email**: Send vulnerability reports directly to `kumararpit17773@gmail.com`.
2. **Details**: Include steps to reproduce the issue, environment setup, and any potential security impacts.
3. **Response Time**: We aim to acknowledge vulnerability reports within 48 hours and provide a patch within 7 business days.

Please do **not** disclose vulnerabilities publicly in public GitHub issues until they have been reviewed and patched.
